# Snowfall

Original 96-second instrumental composed for this portfolio. Soft synthesized piano, sustained pad voicings and stereo room reflections. No third-party recordings, samples or reference melodies are used.

Rebuild with `python minecraft/tools/compose_ambient.py` (numpy and ffmpeg). Runtime plays the local MP3 quietly after a pointer/key interaction. The mute preference persists in localStorage; audio pauses when the tab is hidden and is disposed when leaving the world.
